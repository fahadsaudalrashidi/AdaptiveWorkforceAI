All locally — zero employee data leaves your infrastructure.

## 5. Sales Process

### Discovery to Close (Target: 45–60 days)

```
Day 1–5:    Discovery call — CHRO pain identification, current HR analytics state
Day 6–10:   Platform demonstration with prospect's public sector data (if available)
Day 11–15:  Proof of Concept — AWI analysis on prospect's anonymised sample (50–200 rows)
Day 16–25:  Pilot proposal presentation to CHRO + CTO
Day 26–35:  Legal / procurement review (data processing agreement, PDPL DPA)
Day 36–45:  Contract execution + onboarding
Day 46–60:  First live analysis + first board report delivery
```

### Data Processing Agreement (DPA) Template

Every AWI client receives a DPA that specifies:
- AWI processes employee data only for workforce intelligence purposes
- No employee data is transmitted to any external server
- PDPL Article 6: employees' data processed under legitimate interest (HR management)
- Data retention: session data cleared after 30 days (configurable)
- AWI is the data processor; client organisation is the data controller

## 6. Deployment Models

### 6.1 On-Premises (Current — Default)

**How it works:** Client installs AWI on their own server or secure laptop. No internet required after installation. Data never leaves the client's infrastructure.

**Deployment time:** 2–4 hours with IT team  
**Infrastructure:** Windows Server 2019+ or Ubuntu 22.04+, 8GB RAM, 50GB storage  
**Support:** Remote configuration over VPN or on-site visit

### 6.2 Private Cloud — Client-Hosted (Phase 31)

**How it works:** AWI deployed on client's private cloud (Azure Government, AWS GovCloud, Saudi national cloud). Client controls the cloud instance. AWI SaaS billing model.

**Deployment time:** 4–8 hours with DevOps team  
**Infrastructure:** Docker container on client's Kubernetes cluster  
**Support:** Helm chart provided, AWI support via secure channel

### 6.3 AWI SaaS — Multi-Tenant Hosted (Phase 32, Enterprise/Gov Only)

**How it works:** AWI operates a Saudi-hosted multi-tenant SaaS platform on a local cloud provider (e.g. STC Cloud, Alibaba Cloud KSA). Client data processed in Saudi Arabia. PDPL Article 21 (data transfer) compliance maintained.

**Deployment time:** 24 hours (account provisioning)  
**Infrastructure:** AWI-managed, SLA 99.9%  
**Note:** Requires explicit client consent for SaaS model. Many government clients will require on-premises model only.
