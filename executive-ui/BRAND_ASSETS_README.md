# THRIVE brand assets

- `public/brand/thrive-logo.png` is the supplied official horizontal full-colour logo.
- `public/brand/thrive-logo-white.png` is a monochrome-on-dark derivative of the supplied artwork, following the guideline's white-logo treatment.
- `public/brand/thrive-mark.png` is the supplied THRIVE mark for the favicon and compact navigation.
- Brand artwork remains the property of THRIVE Business Solutions and should be used only for authorized THRIVE product materials.

## Typography

- The English UI uses self-hosted Arimo font files obtained from Google Fonts in `public/brand/fonts/`. Arimo is distributed under the SIL Open Font License (OFL 1.1); retain the upstream copyright and license notice when redistributing font files.
- Arabic typography uses self-hosted Noto Sans Arabic files obtained from Google Fonts as the fallback in a `GE SS, Noto Sans Arabic` stack. Noto fonts are distributed under OFL 1.1; retain their upstream notices.
- GE SS is the guideline's preferred Arabic face, but no licensed GE SS font files were supplied. The CSS reserves it as the first stack entry without bundling or redistributing it.

License references: https://scripts.sil.org/OFL and https://github.com/notofonts/arabic
